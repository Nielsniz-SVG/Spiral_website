🚀 **3 ÉTAPES POUR LANCER:**

ÉTAPE 1: Configuration Supabase (5 min)
────────────────────────────────────
  1. Créer compte sur https://supabase.com
  2. Créer nouveau projet
  3. Obtenir Project URL + Anon Key
  4. Les copier dans auth.js et dashboard.js
  5. Ajouter votre URL Netlify dans Supabase

ÉTAPE 2: Tester Localement (5 min)
────────────────────────────────
  1. python -m http.server 8000
  2. Ouvrir http://localhost:8000
  3. Tester inscription/login/dashboard
  4. Vérifier pas d'erreurs (F12)

ÉTAPE 3: Déployer sur Netlify (5 min)
───────────────────────────────────
  1. Push code sur GitHub
  2. Connecter GitHub à Netlify
  3. Déployer
  4. Ajouter domaine Netlify dans Supabase
